ES6 Modules: Import and Export

Import and Export are two important features of ES6 Modules. They allow us to split our code into smaller, reusable pieces, making it easier to manage and maintain.

In this example, we have two files: usersData.js and productData.js. We are exporting data from these files and importing them into script.js. This way, we can use the data in our main script without having to include all the code in one file. // 'use strict'; // ysko satta ma use garne ho type="module" atomatic enambe strict it work same.

Types of Exports

There are two types of exports:

1. Named Exports

We can have multiple named exports in a file. We can import them using their names in another file.

For example, we can export usersData and myName from usersData.js and import them in script.js using their names.

Export syntax:

export { usersData, myName };

Import syntax:

import { usersData, myName } from './usersData.js';

Named exports use curly brackets { } while importing.

2. Default Exports

We can have only one default export in a file. We can import it using any name in another file.

For example, we can export productsData from productData.js and import it in script.js using any name.

Export syntax:

export default productsData;

Import syntax:

import productsData from './productData.js';

Default exports do not use curly brackets { } while importing.

Quick Summary

  • Named Export: Multiple exports are allowed.
  • Default Export: Only one default export is allowed.
  • Named Import: Uses { }.
  • Default Import: Does not use { }.
  • Named exports normally use the same name when importing, while default exports can be imported with any name.
